# LetraShqip për macOS

Pasi të shkarkoni skedarin `LetraShqip-macOS-v1.0.0.dmg`, hapeni atë dhe tërhiqni aplikacionin **LetraShqip** brenda dosjes **Applications**. Herën e parë mos e hapni me dy klikime — bëni **klik me të djathtën (ose Control-klik)** mbi aplikacionin, zgjidhni **«Open»** dhe më pas përsëri **«Open»**, sepse aplikacioni nuk është i certifikuar nga Apple dhe ndryshe macOS do ta bllokojë me mesazhin "cannot be opened". Aplikacioni kërkon **macOS 14 (Sonoma)** ose më të ri.
